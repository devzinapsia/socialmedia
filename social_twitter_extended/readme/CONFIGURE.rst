#. Go to *Social Marketing > Configuration > Social Accounts*.
#. Open an X account.
#. Enable *Pro account (extended character limit and Articles)*.

This checkbox is a configuration flag only: Odoo does not check the real
subscription of the account on X.

To use the campaign reply, set *Fixed reply template for X* on the
campaign (*Social Marketing > Campaigns*, or any UTM campaign form).

To publish Articles, the X account must be flagged as *Pro account* in
Odoo **and** have an X subscription including Articles (X Premium) on X.
