#. Create a post in *Social Marketing* and select only Pro X accounts.
#. Write a text longer than the standard X limit: the counter shows the
   length without a maximum, and the preview shows the whole text.
#. Post or schedule it. If X rejects the text, the error returned by X is
   shown on the post of that account.

Thread:

#. On a post with at least one X account, enable *Is a thread*.
#. Add the next posts of the thread and order them.
#. Post or schedule it.

Campaign reply:

#. Select a campaign with a fixed reply for X on the post.
#. Fill in *Reply URL for X*.
#. When the post is published, the reply is posted under it (or under the
   last post of the thread).

X Article:

#. Go to *Social Marketing > X Articles* and create an Article.
#. Choose a Pro X account, write or paste the body, optionally add a
   cover image, a campaign and a reply URL.
#. Click *Publish*. On error, the message returned by X is shown on the
   Article: fix the cause, then *Reset to draft* and publish again.
