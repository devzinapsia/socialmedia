Social LinkedIn extended

First comment on LinkedIn posts, instant and scheduled

Right after a post is published on a LinkedIn page, Odoo adds a first comment written by the same page, e.g. to share the external link outside the body of the post. Works for posts sent now and scheduled posts, on every selected LinkedIn page, with tracked links and a default comment per campaign.

The post always stays published: temporary errors are retried automatically, the others can be retried by hand, and a comment is never posted twice. The status of the comment is shown for each LinkedIn account on the post.

A diagnostics tool checks whether a page can comment through the LinkedIn API, with a report that never shows the access token. The LinkedIn API version of these calls is a system parameter, easy to update when LinkedIn retires a version.
